# Sahil Swain — Backend Engineer & AI Automation Builder

Personal portfolio focused on Java/Spring Boot backend engineering, practical automation, and AI-assisted engineering systems.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- Vitest

## Local development

    npm install
    npm run dev

Open `http://localhost:3000`.

## Validation

    npm test
    npm run typecheck
    npm run lint
    npm run build

The production build uses Next.js static export and generates the deployable site in `out/`.

## Deployment

The portfolio is configured for static deployment on Cloudflare Pages.

Build command:

    npx next build

Output directory:

    out

## Repository structure

    src/        Application routes, components, configuration, content, and tests
    content/    Runtime data used by the portfolio
    public/     Static deployment assets and hosting headers
